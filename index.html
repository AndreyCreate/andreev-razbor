Почему такой порядок

Слева направо — от главного продукта к самому личному. Hey, Andrey! первым, потому что это основная работа. «Отзывы» сразу за ним: это доказательство к первому кружку, а не отдельная тема. Дальше два личных блока, их открывает тот, кто уже заинтересовался: «Кто я», а последней «Гимнастика», которая в конце возвращает к работе. Порядок от тебя оставил, менять не за чем. Как собрать в Instagram

Instagram ставит первым тот блок, в который последним добавили сторис. Поэтому собирать в обратном порядке: «Гимнастика», «Кто я», «Коучинг», Hey Sash, «Отзывы» и последним Hey, Andrey!. Если потом докинешь сторис, например, в «Гимнастику», она уедет в начало, и порядок придётся восстанавливать. Старые восемь блоков не удалять, а убрать в архив: сторис из них останутся у тебя. Обложки — квадрат 1080×1080, надпись в центральном круге ⌀780, при выборе обложки в Instagram ничего не обрежется.

Приложение

Что не удалось получить

—follows и profile_visits по каждому посту. Graph API их для этого аккаунта не отдаёт ни для каруселей, ни для рилсов. «Какой пост приводит подписчиков» напрямую не считается; пришлось сопоставлять дневной прирост с датами постов.
—profile_links_taps. Отдаёт 0 за все три 30-дневных окна. Отличить «нет кликов» от «метрика не собирается» по API нельзя.
—Follower_count по дням глубже 30 дней. API отдаёт только последние 30 дней, за июнь-июль прирост сравнить не получится.
—Кривая удержания рилсов по секундам. В API её нет, только средний просмотр и доля пропусков. По 13 рилсам в ленте: средний просмотр 10,9 с, доля пропусков 48,6 %.
—Реальные ссылки внутри воронки «экскурсия». Они персональные, выдаются вебхуком под конкретного человека. Проверить их можно только войдя в воронку живым контактом, чего я не делал.
—Число фактических продаж. Оплаты идут на Create Today мимо ChatPlace, в воронке soldProducts = 0 по техническим причинам, из этого нельзя делать вывод об отсутствии продаж.
—Вид профиля глазами постороннего. Снято из твоей же сессии, поэтому на скриншоте кнопки «Редактировать профиль» вместо «Подписаться». Текст био, ссылки и обрезка под «ещё» от этого не меняются.
