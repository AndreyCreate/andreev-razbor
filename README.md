# andreev-razbor

Разбор @andreyandreev.me (17.09.2026) + кнопки генерации (26.09.2026). Статика на GitHub Pages, noindex.

## Кнопки генерации — как устроено

Три кнопки в разделе `#gen` (и дублирующие `.gjump` в разделах «Шапка», «Актуальные», «Лента»):
`highlights` — обложки актуальных, `post` — следующий выпуск лучшей серии, `bio` — три варианта шапки.

Сейчас **демо**: по клику идёт анимация шагов (6–10 с), потом рендерится результат,
собранный заранее и лежащий в `gen/<profile>/`:

```
gen/andreev/
  result.json            — всё, что рисует фронт (формат ниже)
  highlights/*.png       — 6 обложек 1080×1920, 6 круглых превью, bylo_*.png, highlights.zip
  post/s0..s6.jpg        — обложка + 6 кадров 1080×1350, caption.txt, cusk_part2.zip
```

Профиль выбирается параметром `?p=<id>` (по умолчанию `andreev`) → `gen/<id>/result.json`.

## Переход на живую генерацию

Во фронте одна точка замены — функция `generate(kind)` в конце `index.html`.
Достаточно задать `GEN.endpoint = "https://<worker>/generate"`: фронт начнёт слать
`POST {kind, profile}` и ждать JSON вида

```json
{"kind":"post","base":"https://<r2-or-worker>/gen/<profile>/","profile":{...,"cta":{...}},"data":{...}}
```

где `data` — ровно тот же объект, что сейчас лежит в `result.json[kind]`
(пути к картинкам относительные к `base`). Анимация в живом режиме идёт, пока не придёт ответ,
минимальная задержка отключается.

Воркер (Cloudflare Worker + Claude API), по шагам:
1. профиль: Instagram Graph / скрейп → публикации с охватами, актуальные, шапка;
2. `post`: сортировка по охвату → серия → цитатник/материал → Claude собирает тексты кадров и подпись;
   рендер кадров — HTML-шаблон серии → PNG (Browser Rendering API или внешний рендер-сервис);
3. `highlights`: дизайн-токены с ленты (цвета/шрифты) + структура из разбора → HTML-шаблон → PNG + круги + zip;
4. `bio`: Claude, три варианта, проверка лимита 150 и обрезки после 4-й строки;
5. складывает файлы в R2 под `gen/<profile>/`, возвращает JSON.

Ключ Anthropic хранить в секретах воркера, не во фронте.

Исходники демо-рендера: `~/workspace/clients/andreev_self_review/gen_build/`
(`post.html` + `render_post.py`, `hl.html` + `render_hl.py`, `shot.py` — скриншоты проверки).
